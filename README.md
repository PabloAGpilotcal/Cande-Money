# Cande Money 💙

App para llevar el control de la plata de Cande: efectivo, Mercado Pago y el fondo de Christian para los gastos de Lulu, Ruins y Bailes.

Hecha con amor por papá.

## Cómo publicarla en GitHub (gratis)

1. Entrá a https://github.com y creá una cuenta (o iniciá sesión).
2. Arriba a la derecha tocá **+** → **New repository**.
3. En *Repository name* poné `cande-money`, dejalo en **Public** y tocá **Create repository**.
4. Tocá el enlace **uploading an existing file**.
5. Arrastrá **todos** los archivos de esta carpeta (incluida la carpeta `icons`) y tocá **Commit changes**.
6. Andá a **Settings** → **Pages** (menú de la izquierda).
7. En *Branch* elegí `main`, carpeta `/ (root)`, y tocá **Save**.
8. Esperá 1 o 2 minutos. Arriba de esa misma página aparece el link, parecido a:
   `https://TU-USUARIO.github.io/cande-money/`

## Cómo instalarla en el celular

**Android (Chrome):** abrí el link → menú de los tres puntitos → **Instalar app** (o *Agregar a pantalla principal*).

**iPhone (Safari):** abrí el link → botón **Compartir** (cuadradito con flecha) → **Agregar a inicio**.

Queda con el ícono de "Cande by papá" y se abre como una app normal, incluso sin internet.

## Importante sobre los datos

Los movimientos se guardan **en el celular de Cande**, no en internet. Por eso conviene que cada tanto entre a **Más → Descargar copia de seguridad** y guarde ese archivo (en Drive, por mail, etc.). Si cambia de teléfono, instala la app de nuevo y usa **Restaurar desde una copia**.

## Archivos

- `index.html`: la app completa.
- `manifest.json`: nombre e íconos para instalarla.
- `sw.js`: permite usarla sin internet.
- `icons/`: los íconos.
